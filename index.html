SENTINEL GRID

        
Three cooperating agents triage raw SIEM alerts, enrich them with asset context and hand a ranked queue to the on-call analyst.

        
LOGIC Each agent is a LangGraph node with its own tool set and a hard token budget. The ranker scores on asset criticality × signal confidence; results land in pgvector so a repeat alert returns its prior verdict in one lookup.

VECTORVAULT

        
A retrieval service that fuses dense vectors with BM25, then reranks — because pure embeddings miss exact identifiers.

        
LOGIC pgvector stores the dense index, PostgreSQL full-text handles lexical hits, results merge via reciprocal rank fusion and pass a cross-encoder. Recall@10 went 0.61 → 0.89.
